# 要点を作る過程で見つかった、解説の本文への疑問点

章の冒頭に載せる要点を書く係と、それを本文と照合する係が、本文（`docs/src/ch<N>_points.json`）を読んでいて気づいた点の一覧です。

- どれも「気づいた」段階で、原典には当たっていません（未検証）。本文は直していません。
- 要点（`ch<N>_keypoints.json`）は、ここに挙げた箇所に頼らない形で書いてあります。
- 番号は講義番号と解説の番号です。

## 1 つの解説の中で気になる箇所

- 11-1 解説 6：国内基準の段落で「旧使用指針は」が 2 回続く。後半の値（虚血性心疾患を伴う非心臓手術 8〜10 g/dL、人工心肺使用手術の術後急性期 9〜10 g/dL）は、別の文書の値を旧使用指針として書いている可能性がある。
- 6-10 解説 7：「手術室の心停止は、原因を直せば助かる」は、麻酔が原因の心停止（82% が後遺症なく回復）には当てはまるが、同じ解説にある術前合併症による心停止（86% が死亡）には当てはまらず、一般化が強い。
- 9-2 解説 5：平均血圧 60 mmHg で中心静脈圧が 5 から 10 に上がると灌流圧の差は 55 から 50 で約 9% の低下。本文は 10% としている（丸め）。
- 9-2 解説 8：「麻酔下の出血は代償が効きにくい」の根拠が動物実験で、ヒトでの根拠が示されていない。
- 9-3 解説 6：持続投与の昇圧薬はノルアドレナリンが第一選択、とする根拠が、脊髄くも膜下麻酔下の帝王切開・敗血症・心臓手術に寄っている。麻酔中の低血圧全般に当てはめてよい範囲を本文で示す余地がある。
- 9-7 解説 7：清澄水は 2 時間前まで、に対象の限定（誤嚥リスクの高い患者は別）が書かれていない。
- 9-8 解説 3：動的指標が使えない条件のうち、腹腔内圧の上昇が偽陽性か偽陰性かが、引用した論文の本文と表で食い違うと本文自身が述べており、確認が済んでいない。
- 7-3 解説 4：日本麻酔科学会の指針の図（筋弛緩薬を投与済みなら回復させる）が、英国の指針などと逆向きであると本文自身が述べている。出典の一次確認をしておくとよい。
- 4-14 解説 4：レボドパ静注の換算「経口 100 mg あたり 50〜100 mg」は、原文で確かめておくとよい（指摘した係の確信は低い）。
- 11-1 解説 7：ショック指数 1.4 以上で大量輸血を準備、という閾値は、数値表の出典が複数混ざっており、単独の閾値として使う根拠は弱い。
